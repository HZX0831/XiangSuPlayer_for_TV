# 遥控器与状态验收规格

> 第一轮探索/规格存档。第二轮当前设计与实施以 [DESIGN.md](../../DESIGN.md) 为准；手机客户端缺口已在第二轮恢复。下文保留原始候选和原验收计划，不代表本轮全部已实测。

适用范围：三套方向的共同约束；尚未实现。图稿中焦点仅为静态样例。实现后必须以 Android TV 模拟器和真实遥控器验证，不能以浏览器方向键模拟代替。

## 输入规则

| 状态 | 方向键 | 确定 | 返回 |
| --- | --- | --- | --- |
| 导航/内容浏览 | 每次移动到一个明确邻居；边界停止，跨组按下面定义 | 进入栏目/详情或执行当前标注动作 | 子页上级 → 当前主栏目 → 系统退出；不顺带停歌 |
| 电视输入 | 输入法内由 IME 接管；外层不拦截候选选择 | 输入法提交或搜索按钮提交 | 首次关闭 IME 并回搜索按钮，下一次离开搜索 |
| 播放普通态 | 控件之间按空间移动；不在整页拦截左右直接快进 | 执行当前控制 | 退回打开播放器前的条目，保持播放 |
| 进度轨道聚焦 | 左右以 5 秒步进开始预览，连续按按同一步长；界面显示预览时间 | 提交预览；无预览时进入定位 | 取消预览，实际播放位置不改 |
| 纯歌词态 | 第一次仅唤醒控制栏，消耗该次按下和释放 | 第一次仅唤醒，之后执行焦点动作 | 回普通态；再按才离开播放器 |
| 侧面板/对话层 | 只在最上层中移动；首尾不跳入背后页面 | 执行/展开条目 | 关闭一层并恢复具体调用项 |
| 系统媒体键 | 不受页面位置影响 | Play/Pause/Next/Previous 由既有媒体服务处理 | 不改变系统音量键语义 |

5 秒是本轮设计建议，未来不得未经核对就改变现有定位逻辑。MENU、长按、数字键可选配快捷方式，所有同等功能须有普通焦点路径。系统媒体键继续使用既有服务契约。

## 首页的空间拓扑

| 方向 | 从内容到导航/入口 | 从导航回内容 | 从内容到底部播放条 |
| --- | --- | --- | --- |
| A | 内容左边界按左 → 当前竖栏目；栏目上下仅改焦点 | 按右回该页最近条目，确定才提交栏目切换 | 内容最后一行按下 → 播放条记忆控制；按上回原内容位置 |
| B | 内容顶边界按上 → 当前顶部栏目；左右只移动栏目焦点 | 按下回当前页最近条目 | 主画面下 → 三任务行下 → 播放条；反向逐组恢复 |
| C | 内页首行上 → 面包屑首页；确定回 P01 的原入口 | 首页左主区右 → 右栏记忆项；左回主区，确定进入 | 首页右栏末项下 → 播放条；内页内容末行下 → 播放条 |

跨分组恢复不能依赖屏幕像素最近邻自动猜测。焦点 key 使用页面、内容来源与稳定身份；队列用 entry.id，目录用 folder.id/path/entry，榜单用 platform/board.id。回页先滚动到该 key 再请求焦点；条目已经不存在则同组最近幸存项 → 主动作 → 导航当前项。异步列表更新只保留/修复失效焦点，不抢走其他组有效焦点。

## 播放与点歌的完整层级

P10 播放控制 → 更多 → 评论/音源 → 返回更多原条目 → 返回主控制原按钮。队列 → 条目更多 → 设为下一首/移除 → 回原条目或最近幸存项。错误消息在关闭前有稳定可读位置，不能仅 toast。

进入 P15 双行点歌之前，入口旁说明“将暂停普通播放并暂存当前队列”。确定进入时才调用 beginKaraoke；遥控器经过该入口不触发。普通队列被保存，独立点歌队列最多 100 条，第一首成功加入会开始播放。退出调用 endKaraoke，恢复普通队列与位置，保持暂停，由用户再次按播放；不丢弃普通队列、不将点歌曲目混入普通收藏。现有源码依据 PlaybackEngine.kt:816–866。

双行歌词只是显示与点歌模式；没有麦克风权限、录音、音高评分或伴奏按钮。没有 YRC 时用真实 LRC 行级进度；没有逐字时间就不模拟逐字高亮。

## 长内容与显示范围

- 曲名：列表固定两行上限，单行过长不循环跑马；可在详情展开完整标题。演示验收样本含 2 字、12 字、32 字、混合拉丁文和 emoji。
- 歌手：一行摘要，完整名单在详情；没有标签则显示“歌手信息未提供”，不留下空白导致错位。
- 歌单：两行标题；曲数显示已加载/总数，加载未完成不能写“共 X 首”冒充全量。
- 歌词：普通页当前句最多两个视觉行；译文另用两行；双行点歌每句至多两个视觉行。更长句可按歌词分段显示/上下滚动，不能缩小到辅助字号。焦点控件不随歌词滚动。
- 评论：完整阅读可上下滚动单条长文；保留用户、时间、点赞数，禁止只截断而没有阅读路径。
- 目录路径：面包屑先显示当前与上级，完整路径放可打开的说明层；长 URI 不进入普通播放标题。
- 列表规模：搜索首屏展示来自现有接口的结果，原搜索分别取歌曲 36/歌单 24；手机 18。只在后端确有分页时提供更多，不能用无限滚动假定已实现。历史最大 200；点歌最大 100；本地目录按现有 more/incomplete 分别显示下一页与不完整提示。
- 字号放大 1.3×：主内容减少行数，导航与控制行允许重排；绝不以缩小文字抵消系统设置。720p/1080p/4K 依据逻辑 dp 与安全区布局；分辨率不能当成固定密度。

## 关键状态与可执行下一步

| 状态 | 应说什么 | 可聚焦动作/回焦 |
| --- | --- | --- |
| 首次无音乐 | “选一首开始听” | 找歌；回到首页同入口 |
| 未登录私人能力 | “登录网易云后使用每日推荐/私人 FM” | 登录或继续浏览热门内容；登录取消回原任务 |
| QQ 无公开歌单 | “该账号没有可读取的公开歌单” | 重新关联/返回曲库；不说 Cookie 失效 |
| 没有匹配歌曲 | “没有找到匹配结果” | 编辑关键词/更换平台 |
| 取流失败 | “这首歌暂时无法播放” + 可展开现有错误 | 重试/换源/下一首；按现有可用契约执行 |
| 试听 | “试听 · 可播放 N 秒” | 保留换源/下一首；未知 N 不伪造数字 |
| WebDAV 不支持定位 | “此来源暂不支持定位” | 跳过只读轨道，时间仍可读 |
| 部分目录结果 | “已显示部分内容，目录列表不完整” | 重试；不能把 incomplete 当成一定有下一页 |
| 本机收藏成功 | “已收藏到本机” | 保持原焦点；无同步字段时不假装已到云端 |
| 手机会话过期 | “配对已结束，重新生成二维码” | 重新配对/关闭 |
| 点歌满 100 条 | “队列已满，移除曲目后再点歌” | 打开队列/返回；不显示加入成功 |
| 清空历史/卸载/同名替换 | 清楚对象与实际影响 | 默认取消；确认后回最近幸存项 |

## 未来实现的验收脚本（本轮未执行）

1. 冷启动有快照：看到曲名与暂停状态；按一次确定开始取流；不能启动自动出声。
2. 无账号首次使用：只用 D-pad 从首页找歌、打开 IME、输入、提交、播一首；关闭 IME 不退出整页。
3. 搜索请求等待时去顶部导航；结果到达后焦点仍在导航；按下回该页可见结果。
4. 歌单滚至第 40 条，打开播放器再返回，仍见第 40 条；切页再回来滚动与焦点恢复。
5. 连续三次同曲入队，移除第二条只删该 entry；设为下一首不误动其他同曲项。
6. 播放页上移到进度，左右预览，返回取消；再次确定提交。seekable=false 时不能进入预览。
7. 播放 90 秒无操作进入纯歌词；首次按右只唤醒，不能跳进度/换曲；第二次才移动控制焦点。
8. 从更多依次进入评论、音源与音质，逐层 Back；每次回到具体调用项。长评论可读完。
9. 暂存普通队列进入双行点歌；手机不可用时电视仍能退出与控制；点歌 100 条满后拒绝第 101 条；退出恢复普通队列与暂停位置。
10. 本地授权目录后拔出 U 盘；显示可重试的授权/文件错误。WebDAV 分别覆盖鉴权失败、无 Range、部分列表、跨层返回与分页。
11. 网易云 QR 过期刷新/取消；QQ 关联公开资料/解绑。匿名与已登录页面内容都正常。
12. 音源同名替换取消、确认；停用全部音源不会自动恢复默认；不兼容脚本能管理但不能误显示可播放。
13. 壁纸从纯黑、纯白到繁杂封面；正文与焦点仍可辨。减少动画、字体 1.3×、读屏、720p/1080p/4K 均覆盖。
14. 系统 Home 后后台续播、媒体暂停键、再打开回页；最终退出 UI 的语义与后台服务既有行为一致。
