## 图稿核验

- 六张单屏图与一张总览图均为 **1920×1080**，16:9；SVG 原稿单屏 viewBox 为 960×540。
- 在本机 Edge headless 渲染后逐张检查六屏，修正封面出界、上一首图标、暂停恢复状态不一致与一处右边界文字超出约 1 个设计单位的问题。
- 最终用浏览器字体实际 getBBox 检查六屏的顶层界面文字，在安全内容范围约 x=48–912 / y=27–513 内，无超出项（字形边缘按 1 个设计单位容差）。封面内题字随图片缩放，不计为可交互正文。
- SVG 封面使用自身 viewport 裁切；首页显示暂停恢复与播放三角，播放页显示正在播放与暂停焦点，状态一致。
- HTML 评审页使用本地 SVG，PNG 提供同版图片输出；不加载远程图片、字体或音乐服务。
