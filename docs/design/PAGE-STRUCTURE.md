# 页面结构与完整功能映射

> 第一轮候选方案与验收计划存档。当前规范见 [DESIGN.md](../../DESIGN.md)，实际结果见 [验收记录](IMPLEMENTATION-REVIEW.md)。

三套方向共享能力范围，页面构图各不相同。本文记录第一轮提出的页面结构。

## 1. 逻辑页面树

~~~text
首页（A:首页 / B:现在 / C:接着听主区）
├─ 继续播放 / 最近播放 → 历史列表 → 播放页
├─ 发现音乐
│  ├─ 日推或游客热门新歌 → 歌曲列表 / 播放全部
│  ├─ 精选歌单 → 歌单详情
│  ├─ 华语 / 欧美 / 日本 / 韩国新歌
│  └─ 私人 FM / 心动模式 → 登录条件说明或播放页
├─ 找歌
│  ├─ 电视输入 / 同网手机输入
│  ├─ 热搜 / 搜索历史 / 清空历史
│  ├─ 歌曲：聚合 / 网易云 / QQ / 酷狗 / 酷我 / 咪咕
│  └─ 歌单 → 歌单详情
├─ 曲库
│  ├─ 我的收藏（本地与网易云红心）
│  ├─ 网易云歌单 / 网易云音乐云盘
│  ├─ QQ 公开歌单 / 酷狗公开榜单
│  ├─ 本地目录 / U 盘 → 授权目录 → 层级 / 分页 / 曲目
│  └─ 网络目录 → HTTPS WebDAV 配置 → 验证 / 层级 / 分页 / 移除
├─ 榜单 → 平台（三项） → 榜单（各十项） → 歌曲
├─ 更多
│  ├─ 最近播放（兼容旧入口）
│  ├─ 双行歌词与点歌 → 进入说明 → 独立点歌界面
│  ├─ 音乐账号 → 网易云登录 / QQ 公开资料关联
│  ├─ 音源管理 → 市场 / 已安装 → 导入 / 安装 / 替换 / 启停 / 测速 / 卸载
│  └─ 设置 → 音质 / 背景 / HTTP 兼容 / 关于与致谢
└─ 全局播放条（浏览页保留） → 全屏播放
   ├─ 上一首 / 播放暂停或重试 / 下一首 / 定位
   ├─ 队列 → 播放条目 / 设为下一首 / 移除
   └─ 更多 → 模式 / 收藏 / 译文 / 纯歌词 / 音源与音质 / 评论 / 双行点歌
~~~

发现音乐是已有发现内容的结构重组；没有新增情绪歌单、运营推荐或家庭成员账户。原“随机漫游”继续在歌单详情，不以新算法名义包装。

## 2. 页面契约

| ID | 页面与必要内容 | 初始焦点 / 返回 | 关键状态 |
| --- | --- | --- | --- |
| P01 | 首页：上次曲目、暂停状态、找歌、曲库、榜单、更多、发现/最近入口 | 有记录落继续播放；无记录落找歌；顶层返回系统退出，不以返回键暂停音乐 | 首次使用、可恢复但未取流、正在播放、离线 |
| P02 | 发现：日推/游客新歌、歌单、FM、心动、四地区新歌 | 当前可用主动作；回首页原入口 | 未登录、空、加载、失败、部分数据可用 |
| P03 | 找歌：输入、手机输入、提交、歌曲平台与歌单类型、热搜/历史、结果 | 电视搜索按钮；编辑返回先收 IME；再回 P01 | 未提交、等待、空、失败、结果、手机消息到达不抢焦点 |
| P04 | 榜单：三平台、十榜目录、榜标题、刷新、播放全部、曲目 | 恢复上次榜；每次进入歌曲前按确定；返回保留平台/榜/滚动 | 缓存结果、更新中、空、失败重试 |
| P05 | 歌单：封面、标题、来源、已加载/总数、全部/随机、歌曲 | 播放全部或无内容时重试；返回原歌单条目 | 部分成功、补齐中、缺曲、空、彻底失败 |
| P06 | 曲库：收藏、网易云歌单/云盘、QQ 公开歌单、酷狗公开榜、本地/网络目录 | 收藏首项或空状态找歌；返回原分类 | 未登录/未绑定、无公开内容、加载/错误 |
| P07 | 目录根/层级：名称、完整路径按需展开、上级、曲目、上下页、添加/移除 | 当前目录首项；Back 逐级上行，到根再退出 | 无选择器、授权丢失、U 盘移除、空、incomplete、more |
| P08 | WebDAV 添加：HTTPS 地址、名称、用户名/密码（可选）、验证并保存 | 地址；返回不保存并回添加入口 | 验证中、证书/鉴权/网络失败、保存成功；密码不明文回显 |
| P09 | 历史：全部播放、单删、清空确认、最多 200 条 | 上次曲目；最后一项删后回可见找歌入口 | 空、清空确认；取消为确认层默认焦点 |
| P10 | 全屏：曲名/歌手/来源、封面、歌词、进度、五个主控制、错误重试 | 播放/暂停；Back 先退出预览/纯歌词/子层，再回调用页 | 无歌词、前奏、译文、加载、试听、不可定位、错误 |
| P11 | 队列：总数、当前条目、曲目、条目更多、关闭 | 当前队列条目或关闭；返回 P10 的队列按钮 | 重复歌曲按 entry.id 分开；当前项被移除后的稳定焦点 |
| P12 | 播放更多：顺序/随机/单曲循环/心动、收藏、译文、纯歌词、音源音质、评论、双行点歌 | 原选择或第一项；子页回具体调用项 | 本地曲目不提供云换源；能力受限给解释 |
| P13 | 音源与音质：四档请求音质、当前档、可用音源、当前流信息 | 当前档位；返回 P12 | Full/Trial、换源等待、失败；实际质量未知不伪造 Hi-Res 标识 |
| P14 | 热门评论：用户/时间/点赞数/正文，只读 | 首条或关闭；长内容上下分段/滚动 | 无评论、加载/失败；无外部匹配的本地曲目说明 |
| P15 | 双行点歌：当前/下一句、逐字或逐行、手机点歌、播放/暂停、跳过、退出、队列/移除 | 手机点歌或已有曲目时播放控制 | 入场前说明会暂存普通播放；空队列、前奏、无歌词、满 100、点歌失败 |
| P16 | 音乐账号：网易云与 QQ 各自状态、QR/刷新/退出/解绑；QQ 号输入 | 平台入口；Back 退出当前层并停止相应轮询 | 生成中、待扫码、已扫码待确认、过期、失败、成功；QQ 只读公开权限 |
| P17 | 音源管理：市场/版本/资源说明/安装，已安装/开关/测速/卸载，自定义 URL | 已安装列表或市场入口；返回原资源 | 不兼容、未测速/测速中/超时、重名替换确认、空配置、导入失败 |
| P18 | 设置/关于：默认四档音质、动态封面背景/壁纸、URL 预览/应用/默认、遮罩浓度、HTTP 兼容、版本/原作者/贡献者/链接 | 当前分类首行；输入返回先收键盘 | URL 无效、预览失败、保存状态；保留全部既有署名而不虚构新信息 |
| P19 | 手机配对层：同网说明、二维码、过期状态、刷新/取消，输入确认或点歌状态 | 取消/关闭；返回原入口 | 无 IPv4/换网、到期、断连、搜索 18 条上限、选项失效、点歌队列满 |

## 4. 手机路径的缺口与恢复方式

原 UI 的 TvPhoneInputDialog 可生成 URL 二维码，但优化后端已移除 HTML 页面；GET 返回 JSON。单独画出二维码不等于实现扫码输入。

后续前端工作应在相同允许的工程范围内补齐配套同源手机界面或经用户选定的客户端载体，遵循已有 Host/Origin 与短期令牌契约。此处不建议另设公开服务器或跨源绕过。手机最小流程：扫码 → 输入关键词 → 提交到电视（搜索输入模式）；点歌模式为扫码 → 搜索 → 选择会话结果 → 收到加入成功/已满/结果过期。每个失败状态保留重试/重新搜索；电视按返回关闭就停止配对。

这项属于未来恢复现有完整体验所必需的接入工作，本轮没有实现，也不承诺现有后端二维码已能直接打开输入网页。

## 5. 功能保留核对

PRODUCT 的 14 个能力域均在 P01–P19 具有入口、返回和状态承载。保留背景自定义能力不等于保留蓝粉流体皮肤。保持双行点歌能力不等于忽略独立队列切换的副作用。没有把“音源市场”“历史”“评论”“随机漫游”“译文”“云盘”藏成未来再说的功能。
