# 三套 TV 音乐播放器设计方向

> 第一轮候选方案与验收计划存档。当前规范见 [DESIGN.md](../../DESIGN.md)，实际结果见 [验收记录](IMPLEMENTATION-REVIEW.md)。

候选提出日期：2026-11-11。产品依据：[PRODUCT.md](../../PRODUCT.md)；代码证据：[仓库审查](REPOSITORY-AUDIT.md)。

先看 [16:9 概念稿评审页](preview.html)，每套包含首页与全屏播放页。图中曲名、歌手、专辑与封面是同一组虚构演示素材，用来公平比较长短文本与布局；不是线上推荐、真实用户收藏或已获授权的商业封面。概念稿展示一个焦点状态，不是 Android 运行截图。

## 为什么是这三套

三套都为“家人共用、简单易找”服务；差别在于组织音乐的方式，不能通过换色相互转换。

| | A · 节目簿 | B · 幕间 | C · 唱片索引 |
| --- | --- | --- | --- |
| 核心动作 | 先选栏目，再认曲目 | 从当前歌曲进入下一项任务 | 一屏认出目的地，进入固定分区 |
| 图形来源 | 家庭节目表、音乐会节目簿 | 剧场字幕、幕间报幕 | 唱片分类目录、中文拼版 |
| 首页结构 | 左侧文字导航 + 中间曲目目录 + 右侧静态唱片页 | 上方文字导航 + 宽阔当前歌曲舞台 + 下方下一步 | 无侧栏的开放矩阵，主任务与四个目的地固定占位 |
| 导航记忆 | 纵向栏目位置 | 水平五项文字位置 | 首页空间位置 + 内页面包屑 |
| 播放结构 | 封面/曲目资料与歌词对页 | 中央大歌词，封面退居侧边 | 歌词/专辑/接下来三块硬分区 |
| 默认色彩 | 暖纸、墨褐、朱红 | 炭黑、象牙、浅苔 | 墨绿、暖白、明黄 |
| 焦点语法 | 朱红实体行 + 小箭头 | 浅苔实心动作 + 外框 | 明黄分区 + 黑色边角记号 |
| 优势 | 家庭成员容易读懂、曲库流程稳 | 远处歌词最突出、听歌时安静 | 路径位置最明确、无需先理解导航栏 |
| 代价 | 列表选曲偏理性，纸色大面积需控亮度 | 发现内容首屏较少，依赖明确下一步 | 模块感最强，需抑制信息密度 |

建议优先讨论 A：它最直接回应“简单易找”，并且能平稳承接目录、榜单和曲库的复杂层级。B 适合把电视主要当歌词与听歌场景；C 适合偏好固定入口、希望一眼认出去哪儿的家庭。此建议不是已选定的实施方向。

## 所有方向共用的电视底线

- 设计坐标为 960×540，概念图输出 1920×1080；生产布局用 dp、文字用 sp，不按物理像素硬编码。关键内容安全边距至少左右 48、上下 27 个设计单位，背景可出血。方向差异发生在安全区内的内容结构。
- 主任务标签 20–24 sp，正文/曲目 20 sp，次要资料 16–18 sp；14 sp 仅用于非关键辅助资料，不能承载操作说明。正文不靠极细字重。双行歌词 36–44 sp，普通当前歌词 28–38 sp；具体换行见交互规格。
- 焦点区域最低 48 dp 高、间距至少 8 dp。图像保持方角；所有候选默认内容区圆角 0，输入/对话层可用不超过 4 dp 的细微圆角。保留标准 Android 返回、输入法、目录授权与读屏行为。
- 焦点是“我马上会操作哪里”；选中是“当前筛选/栏目”；播放中是“哪一条正在响”。分别使用实体填充/指向记号、侧边线/下划线、播放符号与文字，不用同一种亮色表达三个状态。
- 移动焦点即刻可见，120–160 ms 内完成反馈；页面换场 180–220 ms；歌词按时间平稳滚动。不漂浮、不呼吸、不做唱片旋转和假音频波形，不以不断放大卡片表达交互。开启减少动画时瞬切或淡入。
- 五个普通入口保持可见或一步返回首页可见。音源工程参数放在“更多”，不删除。所有重要操作有文字，图标只是辅助。
- 壁纸与封面动态取色能力保留为选项：仅改变图像带/背景的受控区域；导航、焦点、错误色与正文对比独立。纹理、模糊、渐变均不是识别方向的必要条件。
- 不支持拖动的流保持时间文字，轨道显示只读并标“此来源暂不支持定位”。不画假的可用控件。不依赖长按或遥控器专有按键。

以上安全区、dp/sp 和 D-pad 原则参考 Android 官方 [Build TV layouts](https://developer.android.com/training/tv/playback/compose/layouts)；960×540 构图及按决策路径组织焦点参考 [TV Layouts](https://developer.android.com/design/ui/tv/guides/styles/layouts)。本项目的字号、三套配色、焦点样式与时间取值是本轮设计建议，不能冒充官方强制标准。

## A · 节目簿

### 视觉主张

像翻开一本放在客厅的音乐节目簿：栏目在固定的左边，歌曲以目录行展开，右侧留给一张唱片。用页面秩序承接家庭的操作记忆，不以复古皮革、唱机面板或拟物按钮装饰屏幕。

### 视觉系统

| 语义角色 | 值 | 使用规则 |
| --- | --- | --- |
| background / onBackground | #E9E3D5 / #29261F | 暖纸底不是纯白，夜间全屏播放切深墨底 |
| surface / onSurface | #DED6C5 / #29261F | 只用于已聚焦分组的辅助区，不包住每个条目 |
| secondary text | #625A4D | 作者、来源与计数 |
| primary / onPrimary | #9F3526 / #FFF8E9 | 聚焦行、主动作；不为每个分区涂红 |
| outline / current | #786D5B / #9F3526 | 边界；当前播放另加播放符号/“正在播放” |
| player background / text | #24221E / #F4EDDE | 夜间听歌保持同一暖中性色语法 |
| error / onError | #9F3526 / #FFF8E9 | 带“失败/重试”等明确文案，不只换色 |
| disabled | #625A4D，虚线边界 + 原因 | 不降低整行文字至不可读；焦点可到说明项 |

字阶：页面标题 30/38 sp，曲目标题 22/30 sp，行文 20/28 sp，辅助 16/24 sp；时间数字用等宽数字。界面用系统中文无衬线；可仅在页面展示标题试用宋体 30 sp，正文与控件不用宋体。正式字体资产未定，默认方案不新增字体下载依赖。

网格：左右安全边距 48；栏目宽 136；分隔沟 24；中间曲目区 340；右侧资料区 340（含内间距）。内容行高 64，分隔线 1；节奏单位 8。首页首屏给出三条最近曲目与“查看全部最近播放”，不混入长市场公告。

### 页面结构与第一屏

- 首页：左栏“首页/找歌/曲库/榜单/更多”；中列“接着听”，三条曲目；下方“我的收藏”与“发现音乐”文字入口；右列一张方形封面、曲名、歌手和来源，不擅自随焦点切换真实播放。
- 找歌：左栏固定；内容左上输入/手机输入，下面平台与类型为两行文字选项；结果是高行距目录。切换筛选按确定提交。无单独歌手页承诺。
- 曲库/目录：左列分类，中列曲目或目录；右列选中项资料。网易云云盘、QQ 公开歌单、酷狗公开榜与本地/网络目录都在完整分类表里，可滚动而不是挤成横向小胶囊。
- 榜单：平台 → 榜单目录 → 歌曲目录分两次明确进入，返回逐级回到原榜。标题固定显示平台和榜名。
- 播放页：左侧约 300 dp 封面与曲名，右侧约 480 dp 歌词；底部单排方角控制、连续直线进度。队列/评论/更多从右侧资料页展开，不盖住全部播放语境。
- 设置/账号：正文表单与右侧说明，QR 单独白底方形区域，平台登录不伪装成同一账号权限。

### 遥控器特征与风险

首页初始焦点在“接着听”第一条（有暂停恢复记录时为“继续播放”）；无记录时在“找歌”。曲目区左边界按左回当前栏目；从栏目按右回先前条目。曲目列表上下移动，中间不插可聚焦的小徽章。详情/播放器返回恢复条目与滚动。

特色是“目录行展开资料”，不是自动播放预览。内容换图限时淡入，旧封面不影响焦点。主要风险是暖底屏幕较亮；夜间全屏用深色对页，浏览可提供同结构深色版本。后续需验证同一行长曲名和未知歌手，不靠缩小字体补救。

图稿：[首页](concepts/a-home.svg) · [播放页](concepts/a-player.svg)。

## B · 幕间

### 视觉主张

把电视当一面清楚的剧场字幕：现在听的音乐占据横向空间，浏览是一段短暂的幕间。灵感来自舞台上的留白和字幕基线，不使用舞台聚光、烟雾、紫色光晕或动态星空。

### 视觉系统

| 语义角色 | 值 | 使用规则 |
| --- | --- | --- |
| background / onBackground | #141715 / #F0EFE8 | 默认炭黑，大区域平面 |
| surface / onSurface | #242A25 / #F0EFE8 | 下方下一步与展开面板 |
| secondary text | #AEB8AC | 非当前歌词、资料与未选导航 |
| primary / onPrimary | #C5DCAB / #141715 | 可执行主动作及焦点填充 |
| outline / selected | #6E806C / #C5DCAB | 普通边界；选中用下划线，焦点另有完整外框 |
| error / onError | #F1A591 / #141715 | 错误文字或带清楚动作的提示面 |
| disabled | #AEB8AC，斜线图标 + 原因 | 不以隐藏控件制造“消失的功能” |

字阶：当前曲名 38/46 sp；中心当前歌词 38/48 sp；任务 22/30 sp；导航/曲目 20/28 sp；辅助 16/24 sp。只用一套无衬线家族；较轻的展示字重不能低于 400。宽字距仅用于演示封面题字，不用于中文导航和操作标签。

网格：顶部导航高 48；主区高约 280；底部下一步区高 110；底边全局播放状态 48。主区使用横向 60/40 分配；上下区界线清楚；内容安全区相同。页面不变成通用横向无限海报墙。

### 页面结构与第一屏

- 首页：顶部“现在/找歌/曲库/榜单/更多”五项纯文字导航；主区左侧大曲名、来源、继续/进入全屏，右侧 200 dp 方形封面；下方仅三个稳定任务“最近播放/我的收藏/发现音乐”，明确数量与去向。
- 找歌/曲库：任务发生时展开全幅“幕间工作区”，顶部导航不动；左 2/3 为高行距结果，右 1/3 为筛选或详情。输入法关闭返回搜索按钮；手机输入随时可退出。
- 榜单：平台文字行与当前榜标题在上，榜单目录/歌曲各一列。普通导航保持水平，内容上下滚动，不靠横移多层轮播。
- 播放页：中央当前歌词 38 sp、相邻两行 22–24 sp，封面缩为右侧 112 dp 标识；底部按“上一首/暂停/下一首/队列/更多”同一基线排列。进度操作进入独立预览状态。90 秒纯歌词态保留歌词语境。
- 双行点歌：歌词增至 40–44 sp，上下两行各至多两个视觉行；队列与手机点歌从右侧展开。普通播放和点歌为不同队列，入口先说明会暂存普通播放。
- 高级页：设置/音源/账号都沿用幕间工作区；长错误消息在右侧说明区展开，避免挤压歌词舞台。

### 遥控器特征与风险

焦点在主区时，上回当前顶部栏目，下进入三个下一步任务，再下进入底部播放状态；每行左右只移动当前层，不把“左右”偷偷变成换曲。进入播放页默认聚焦暂停/播放。纯歌词态首次方向键只唤醒，不执行第二个动作。

特色是“屏幕为当前歌曲留空”，该空场有任务层级作用。主风险是习惯一次看很多推荐的用户会觉得首屏少；发现页用明确目录补齐全部推荐，不加入无来源的情绪分类或伪个性化文案。

图稿：[首页](concepts/b-home.svg) · [播放页](concepts/b-player.svg)。

## C · 唱片索引

### 视觉主张

像一张放大的唱片目录页，首页每个目的地都有固定位置。用墨绿底、明黄焦点、粗标题和贯穿的网格线建立记忆；没有一张张悬浮卡片，也没有占位装饰数字。

### 视觉系统

| 语义角色 | 值 | 使用规则 |
| --- | --- | --- |
| background / onBackground | #153D33 / #F4F0DF | 墨绿与暖白形成整页印刷面 |
| surface / onSurface | #214C40 / #F4F0DF | 内页辅助分区；不添加阴影 |
| secondary text | #C1CEB6 | 作者、来源与计数 |
| primary / onPrimary | #F0E564 / #153D33 | 当前焦点所在的整块区域或整行，不能整页高亮 |
| outline / selected | #7D9C80 / #F4F0DF | 开放网格；选中另有 3 dp 定位线 |
| error / onError | #FFC1A3 / #153D33 | 明确错误文字和重试 |
| disabled | #C1CEB6，虚线外沿 + 原因 | 当前播放用三角符号/文字，与黄底焦点分开 |

字阶：首页目标 32/40 sp，内页标题 28/36 sp，曲目/操作 20/28 sp，辅助 16/24 sp，当前歌词 36/46 sp。展示标题可用系统粗体 700，正文 400–500；中文不压缩、不倾斜。数字只在榜单真实排名、队列位置和计数出现。

网格：首页以安全区 864×486 为完整画布，上方标题 52、下方播放状态 56，中间 378 分为左 2/3 主任务和右 1/3 四条目的地；1–2 dp 连续规则线承载分区，无间隙卡片投影。内页使用 8 dp 间距、高 56–64 dp 列表行；允许图像本身有独立边界。

### 页面结构与第一屏

- 首页：左大区是“接着听”与上次曲目信息、方形封面和明确的播放按钮；右侧固定“找歌/曲库/榜单/更多”四个大目标。无上次记录时左区变为“选一首开始”并链接找歌，不展示虚假历史。我的收藏在曲库首项，最近播放在接着听的次入口。
- 内页：左上“首页 / 当前目的地”的可聚焦面包屑；内容按相同硬网格展开，导航上移可见而不是藏入图标抽屉。返回首页能记住原来入口。
- 搜索：上方全宽输入与手机输入；下面左筛选、右歌曲表。焦点从输入区下到结果表，再从首行上返回提交位置。热搜/历史在未提交时占结果区，避免同时挤进三套小标签。
- 曲库/榜单/目录：固定两栏或三栏表格；一列只承担一种层级，不将云盘、公开榜单和登录控件混为同类收藏。表格容许上下滚动，禁止让横向大表超出安全区。
- 播放页：左 2/3 是当前歌词与相邻行，右上专辑、右下“接下来”只读摘要；底部五个控制组成连续操作行。摘要按确定才进入可操作队列，不把每个摘要重复做焦点目标。
- 设置/账号/音源：分类索引 + 高行距设置表。状态、值、操作分列，保持一行一个主焦点；“卸载/替换”移入明确的更多动作。

### 遥控器特征与风险

首页起点在左侧继续播放；右进入右栏记忆项，右栏上下移动；左回继续播放。右栏上下到边界停止，不环绕到别的栏目。进入目的地后焦点落首个主要动作；返回恢复入口。一次学习可复用固定位置。

特色是“大字分区的空间记忆”，黄底表示现在能操作的区域。主风险是面积强、久看容易像标牌；只保留真实目的地文字与必要曲目信息，不添加海报口号；夜间可在相同结构下减小黄底面积为黄边框。

## 共同组件与状态字典

| 组件 | 默认/选中/焦点 | 进行中/异常 |
| --- | --- | --- |
| 主导航 | 稳定文字位置；选中有线；焦点有完整边界 | 页面加载不挪导航、不转移焦点 |
| 曲目行 | 标题/歌手/来源；播放中有符号与文字；焦点整行实体或明确框 | 长曲名两行/详情；缺封面用标题首字的统一方形占位 |
| 歌单/专辑图 | 方形图片 + 外部题注，无圆角背景卡 | 缺图保留尺寸，加载和失败不引起重排 |
| 全局播放条 | 当前曲/暂停状态 + 播放/上下首/打开全屏/模式 | 空时只给“找首歌”；错误给重试，不依赖短暂 toast |
| 播放控制 | 图标 + 字；选中模式有文字；焦点实色 | loading 标明正在取流；连按不重复提交破坏状态 |
| 弹层/侧面板 | 标题、操作与关闭；焦点限制在内部 | 返回关闭最顶层；回到原调用项；被移除时选择最近幸存项 |
| 输入 | 聚焦外框；确定打开 IME | 等待验证显示文字；提交失败保留原输入 |
| 切换项 | 名称 + 当前值/开关；不能只放小开关 | 不可用时原位给原因，提供可达下一步 |
| 错误/空状态 | 一句话说明 + 清楚主动作 | 部分成功仍可播放已加载项，保留“重试剩余” |

## 进入实现前的交付边界
