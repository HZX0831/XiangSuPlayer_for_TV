# 像素播放器 TV v2.1.0 preview

面向电视遥控器和 16:9 大屏的 Compose 重构预览版。延续像素播放器安卓版的品牌语言，以“封面节目册”组织首页、曲库和沉浸播放；应用 ID 保持 `com.cutedino.xiangsuplayer`。

## 主要变化

- 五个文字栏目、独立 MiniPlayer、标准／紧凑布局和大字号适配。
- 全屏封面与歌词、纯歌词、进度预览确认／取消、队列条目级操作与焦点恢复。
- 统一遥控器输入、弹层返回、加载／空结果／失败与重试状态；歌单部分成功即可播放。
- 保留多平台搜索、账号、收藏、歌单、榜单、目录、音源管理、手机输入和独立点歌队列。
- 后台播放与冷启动暂停恢复；Room 迁移、歌词、取流竞速、WebDAV 和手机协议回归。

## 发布前修正

- 更正作者：Android 主项目作者 R3n_011；cutedino 为 TV 原维护者，HZX0831 为 TV 现维护者；暮间雾列入鸣谢。
- 关于页读取实际版本号，避免版本说明过期。
- 桌面名称去除旧版号；图标合并重复资源、更正 PNG 后缀，并支持 Android 自适应遮罩。
- 修复并发网易云响应互相覆盖 Cookie 的问题。
- 修复音源市场把请求失败错误显示为空市场的问题。
- 修复跨平台数字歌曲 ID 被直接用于网易云评论的问题。

## 验证与边界

Debug 与 AndroidTest 构建、48 项 JVM 回归、两个模块 Lint 已通过；Lint 零错误，既有警告数量未增加。原生截图、D-pad 路径及详细验证范围见 [验收记录](../design/IMPLEMENTATION-REVIEW.md) 和 [发布前检查](../RELEASE-REVIEW-v2.1.0-preview.md)。

这是预览版。第三方服务、真实账号授权、实体手机／电视、WebDAV 服务及低性能盒子的兼容性取决于实际环境；未经本机验证的项目仍在验收记录中列明。请求音质不代表实际解码质量；音源市场不执行任意 JavaScript。

本预览版使用新的发布证书，无法直接覆盖 `2.0.0_Preview_with_vss`。旧版用户需先妥善保存需要的数据；卸载会清除应用本地数据。
